# Changelog

## 0.1.0 release candidate

- Added exact decimal arithmetic with separate numeric, raw, and display properties.
- Added a generic filtered related-difference sum for conditional credit-minus-debit style calculations.
- Added configurable reciprocal single-to-many relationships.
- Added disabled, preview, and active rule states.
- Added metadata-only journals, bounded undo, accepted-state recovery, stale-preimage checks, and a three-failure circuit breaker.
- Added schema-zero migration and fail-closed handling for unknown schemas.
- Verified install, preview, apply, undo, unload, migration, rejection, and recovery in an isolated Obsidian vault.
- Documented generic numeric and reciprocal-relationship examples plus the preview-first activation workflow.
